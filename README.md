## Постановка контрольной работы №1

Тема контрольной работы №1: «HTML и CSS: разработка многостраничного сайта».

В рамках контрольной работы необходимо разработать многостраничный HTML/CSS-сайт интернет-магазина или каталога услуг.

Проект должен включать:

- главную страницу;
- страницу каталога;
- страницу карточки товара или услуги;
- страницу оформления заявки;
- страницу контактов;

- внешний CSS-файл;
- базовую навигацию;
- оформление основных блоков страницы.

## Реализованные элементы интерфейса

- сообщение об успешной отправке.

## CSS-архитектура

В проекте используются:

- CSS-переменные в `:root`;
- единая шкала отступов;
- переменные для цветов и скруглений;
- состояния `:hover`, `:focus-visible`, `:disabled`;
- визуальная подсветка ошибочных полей через `aria-invalid`;
- структурированный файл `css/style.css`: сначала переменные и базовые стили, затем по одному разделу на каждый БЭМ-блок.

## Позиционирование

- `position: relative` — карточка товара `product-card` как контейнер для бейджа;
- `position: absolute` — бейджи «Хит», «Новинка», «Скидка» в углу карточки;
- `position: sticky` — шапка сайта и блок фильтров в каталоге;
- `position: fixed` — кнопка «Наверх» в правом нижнем углу;
- `z-index` — шапка и кнопка «Наверх» отображаются поверх содержимого (значения вынесены в переменные `--z-header`, `--z-to-top`).

## Использование Flexbox и Grid

В проекте используются:

- Flexbox для основного меню;
- Flexbox для внутренней структуры карточек товаров;
- CSS Grid для сетки карточек;
- CSS Grid для страницы каталога с фильтрами и списком товаров;
- CSS Grid для блока преимуществ и страницы товара.

## БЭМ-структура проекта

В проекте используются следующие БЭМ-блоки:

- `site-header` — шапка сайта;
- `site-nav` — основная навигация;
- `breadcrumbs` — хлебные крошки;
- `hero` — первый экран главной страницы;
- `section` — универсальный раздел страницы;
- `advantages` — преимущества магазина;
- `product` — страница товара;
- `product-table` — таблица характеристик;
- `to-top` — фиксированная кнопка «Наверх»;
- `products-grid` — сетка товаров;
- `product-card` — карточка товара;
- `info-note` — информационный блок;
- `contacts-list` — список контактов;
- `catalog-layout` — структура страницы каталога;
- `catalog-filters` — фильтры каталога;
- `filters-form` — форма фильтров;
- `order-dialog` — модальное окно заявки;
- `order-form` — форма заявки;
- `success-message` — сообщение об успешной отправке;
- `button` — кнопка;
- `site-footer` — подвал сайта.

Примеры элементов (`блок__элемент`): `site-nav__link`, `product-card__title`, `product-card__price`, `order-form__input`, `breadcrumbs__current`.

Примеры модификаторов (`блок--модификатор`): `site-nav__link--active`, `button--primary`, `button--secondary`, `product-card--discount`, `order-form__field--checkbox`.

Правила, которых придерживается проект:

- стили задаются только через классы, `id` используются для якорных ссылок и JavaScript;
- нет inline-стилей;
- нет глубоких вложенных селекторов;
- модификатор всегда используется вместе с основным классом.
